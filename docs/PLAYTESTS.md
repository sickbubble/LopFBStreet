# Playtests

The concept test's result. Every session in which someone plays the web build:
who played (by role, never by name), what build, what they said **verbatim**,
and what was seen. Interpretation goes in its own column, never mixed into the
quote.

This file is what the Godot build inherits as evidence. A complaint about the
touch is about the web's lean touch, a stand-in (IMPLEMENTATION.md §
*Stand-ins*); mark it so, because it may not apply to Godot's.
