# Prototypes

`alman-ayligi.html` is the single-file browser prototype of 2026-10-05 (three.js r128 from a CDN, no build step). It is the reference for how C1 and C2 should play: the keep-up by height, the strike with the release-now arc, the bot keeper and the 9 Aylık scoring. Open it straight in a browser. It is not part of the build and is not maintained.
